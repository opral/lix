# Getting started

Choose your SDK. Both quickstarts create a repository, write a file, inspect
its history, and undo a change.

## JavaScript

Use JavaScript in Node.js or the browser.

```bash
npm install @lix-js/sdk
```

[Start the JavaScript quickstart →](./javascript-quickstart.md)

## Rust

Use Rust for native applications, embedded services, and Lix servers.

```bash
cargo add lix
```

[Start the Rust quickstart →](./rust-quickstart.md)

After the quickstart, choose a persistent local or hosted setup in
[Persistence and Storage](./persistence.md).
